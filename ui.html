1. Write the debugger firmware

Connect the board's UART USB port. This erases the board, including its saved Wi-Fi network.

2. Connect the board to Wi-Fi

A new board starts its own network, esp-openocd, with no password. It does the same when it cannot reach its saved network. Join that network, then save yours here. Use a 2.4 GHz network.

USB tools

Show board address restarts the board and reads its address. Clear saved network removes the saved network and target settings, but keeps the firmware.
